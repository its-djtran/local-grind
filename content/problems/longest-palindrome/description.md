You are given a string `s` made of lowercase and uppercase English letters. Using some or all of these letters, each at most as many times as it appears in `s`, and arranging them in any order, build the longest possible **palindrome**. Return its length.

Letters are **case-sensitive**: `"Aa"` is not a palindrome, because `'A'` and `'a'` are different characters.

<!-- examples -->

**Constraints:**

- `1 <= s.length <= 2000`
- `s` contains only lowercase and/or uppercase English letters.
