Given a string `s`, count how many of its substrings are **palindromes**, that is, read the same left to right and right to left.

A substring is a contiguous, non-empty block of characters. Substrings are counted by position, so two equal substrings that start or end at different indices are counted separately.

<!-- examples -->

**Constraints:**

- `1 <= s.length <= 1000`
- `s` contains only lowercase English letters.
