Given an integer array `nums`, return the length of its longest **strictly increasing subsequence**.

A subsequence keeps some (possibly all) of the elements in their original order and drops the rest; the kept elements do not have to be adjacent. It is strictly increasing when every kept element is larger than the one kept before it.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

**Follow-up:** Can you design an algorithm that runs in `O(n log n)` time?
