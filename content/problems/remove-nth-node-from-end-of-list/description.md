You are given the `head` of a singly linked list and an integer `n`. Delete the `n`-th node **counting from the end** of the list (the last node is the 1st from the end), and return the head of the resulting list.

<!-- examples -->

**Constraints:**

- The list contains `sz` nodes.
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**Follow-up:** Can you do it while walking the list only once?
