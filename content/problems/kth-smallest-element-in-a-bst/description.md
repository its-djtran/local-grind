You are given the `root` of a binary search tree and an integer `k`. Return the `k`-th smallest value stored in the tree, where counting starts at `1` (so `k = 1` asks for the minimum).

<!-- examples -->

**Constraints:**

- The tree contains `n` nodes.
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

**Follow-up:** Suppose the tree is modified often by insertions and deletions, and you also need to answer k-th smallest queries often. How would you change your approach?
