You are given the heads of two singly linked lists, `list1` and `list2`, each already sorted in non-decreasing order.

Combine them into a single sorted list by relinking the existing nodes (splicing them together rather than creating new values), and return the head of the combined list.

<!-- examples -->

**Constraints:**

- Each list contains between `0` and `50` nodes.
- `-100 <= Node.val <= 100`
- Both `list1` and `list2` are sorted in non-decreasing order.
