You are given an integer array `nums` whose elements are all **distinct**. Return its **power set**: every possible subset of the elements, including the empty subset and the whole array.

Each subset must appear exactly once. The subsets, and the elements inside each subset, may be listed in any order.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- All the numbers of `nums` are **unique**.
