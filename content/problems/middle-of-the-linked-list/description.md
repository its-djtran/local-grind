You are given the `head` of a singly linked list. Return the node in the **middle** of the list.

When the list has an even number of nodes, there are two middle nodes; return the **second** of them.

The returned node is judged by reading the list from that node to the end.

<!-- examples -->

**Constraints:**

- The list contains between `1` and `100` nodes.
- `1 <= Node.val <= 100`
