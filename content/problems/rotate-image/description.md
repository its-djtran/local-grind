You are given a square `n x n` grid `matrix` that represents an image. Turn the image a quarter turn **clockwise** (90 degrees).

The rotation must happen **in place**: change the values inside `matrix` itself rather than building a second 2D grid and returning it. The function returns nothing.

**Constraints:**

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`
