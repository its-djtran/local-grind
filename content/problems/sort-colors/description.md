An array `nums` holds `n` objects, each painted red, white, or blue, encoded as the integers `0`, `1`, and `2` respectively.

Rearrange the array **in place** so that all reds come first, then all whites, then all blues. The function returns nothing; `nums` itself is checked afterwards.

Solve it without calling a library sorting routine.

<!-- examples -->

**Constraints:**

- `n == nums.length`
- `1 <= n <= 300`
- Each `nums[i]` is `0`, `1`, or `2`.

**Follow-up:** Can you do it in a single pass using only constant extra space?
