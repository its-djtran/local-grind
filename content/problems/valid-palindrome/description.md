A phrase counts as a **palindrome** if, after converting every uppercase letter to lowercase and throwing away every character that is not a letter or a digit, the characters that remain read the same from left to right as from right to left.

Given a string `s`, return `true` if it is a palindrome under this rule and `false` otherwise.

Digits are kept just like letters, and an input that has no letters or digits at all counts as a palindrome.

<!-- examples -->

**Constraints:**

- `1 <= s.length <= 2 * 10^5`
- `s` consists only of printable ASCII characters.
