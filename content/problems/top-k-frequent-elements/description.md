Given an integer array `nums` and an integer `k`, return the `k` values that occur **most often** in `nums`. The values may be returned in any order.

The input is chosen so that the answer is unique: there is never a tie for the last of the `k` places.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `k` is between `1` and the number of distinct values in `nums`.
- The set of the `k` most frequent values is unique.

**Follow-up:** Can you do better than `O(n log n)`, where `n` is the length of the array?
