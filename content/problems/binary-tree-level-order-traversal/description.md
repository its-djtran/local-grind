Given the `root` of a binary tree, list its node values **level by level**: first the root, then every node one edge below it, then every node two edges below it, and so on.

Return a list of levels, where each level is the list of values at that depth ordered from left to right. An empty tree has no levels.

<!-- examples -->

**Constraints:**

- The tree contains between `0` and `2000` nodes.
- `-1000 <= Node.val <= 1000`
