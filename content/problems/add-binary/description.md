You are given two strings `a` and `b`, each holding a binary number made of the characters `'0'` and `'1'`. Add the two numbers and return their sum, also written as a binary string.

<!-- examples -->

**Constraints:**

- `1 <= a.length, b.length <= 10^4`
- `a` and `b` contain only the characters `'0'` and `'1'`.
- Neither string has leading zeros, except for the number zero itself (`"0"`).
