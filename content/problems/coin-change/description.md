You are given an array `coins` holding the face values of the available coin types and an integer `amount`. You have an **unlimited supply** of every coin type.

Return the **smallest number of coins** whose values add up to exactly `amount`. If no combination of coins reaches that total, return `-1`.

<!-- examples -->

**Constraints:**

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`
