You are given an array `lists` holding the heads of `k` singly linked lists. Each list is sorted in ascending order.

Merge all of them into one list that is also sorted in ascending order, and return its head.

<!-- examples -->

**Constraints:**

- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- Every `lists[i]` is sorted in ascending order.
- The lists contain at most `10^4` nodes in total.
