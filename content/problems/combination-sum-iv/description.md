You are given an array `nums` of **distinct** positive integers and a positive integer `target`. Count the **ordered sequences** of numbers drawn from `nums` whose sum is exactly `target`. Each number may appear in a sequence any number of times, and sequences containing the same numbers in a different order are counted as different.

The tests are built so that the answer fits in a 32-bit signed integer.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 1000`
- All values in `nums` are distinct.
- `1 <= target <= 1000`

**Follow-up:** Suppose `nums` could also contain negative numbers. What would go wrong, and what extra restriction would the problem need to stay well-defined?
