Given an integer array `nums`, find the contiguous, **non-empty** block of elements (a subarray) whose elements add up to the largest possible total, and return that total.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

**Follow-up:** Once you have the `O(n)` solution, try a divide-and-conquer approach as well; it is less efficient but a good exercise.
