You are given an integer array `nums` and an integer `target`. Return the **indices** of the two numbers whose sum equals `target`.

Every input has **exactly one** valid answer, and the same element may not be used twice.

The two indices may be returned in any order.

<!-- examples -->

**Constraints:**

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- Exactly one valid answer exists.

**Follow-up:** Can you find an algorithm that runs in less than `O(n^2)` time?
