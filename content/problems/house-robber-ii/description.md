This time the houses are built in a **circle**: the last house is a neighbor of the first one. `nums[i]` is the cash stored in house `i`, and robbing **any two neighboring houses** on the same night sets off an alarm.

Return the **largest total amount** you can collect without robbing two adjacent houses, remembering that the first and the last house count as adjacent.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`
