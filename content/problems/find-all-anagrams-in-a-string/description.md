You are given two strings `s` and `p`. Find every position in `s` where a substring begins that is an **anagram** of `p`, that is, a substring of length `p.length` containing exactly the same letters as `p` with the same multiplicities, in any order.

Return the list of those starting indices. The indices may be returned in any order.

<!-- examples -->

**Constraints:**

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` and `p` contain only lowercase English letters.
