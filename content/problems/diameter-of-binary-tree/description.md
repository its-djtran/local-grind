Given the `root` of a binary tree, return its **diameter**.

The diameter is the length of the longest path between any two nodes of the tree, where a path's length is the number of **edges** it uses. The longest path may or may not go through the root.

<!-- examples -->

**Constraints:**

- The tree contains between `1` and `10^4` nodes.
- `-100 <= Node.val <= 100`
