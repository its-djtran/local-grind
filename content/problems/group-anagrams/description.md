You are given an array of strings `strs`. Partition the strings into groups so that two strings are in the same group exactly when they are **anagrams** of each other, meaning one can be rearranged into the other using every letter exactly once.

Return the groups. Both the order of the groups and the order of the strings inside each group are up to you.

<!-- examples -->

**Constraints:**

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` contains only lowercase English letters.
