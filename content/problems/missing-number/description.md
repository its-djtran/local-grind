You are given an array `nums` holding `n` **distinct** integers, each taken from the range `[0, n]`. Since the range contains `n + 1` values, exactly one of them is absent from the array. Find and return that missing value.

<!-- examples -->

**Constraints:**

- `n == nums.length`
- `1 <= n <= 10^4`
- `0 <= nums[i] <= n`
- All values in `nums` are distinct.

**Follow-up:** Can you solve it in `O(n)` time while using only `O(1)` extra space?
