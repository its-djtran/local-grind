You are given an integer array `nums` of length `n`. Return its **majority element**: the value that occurs **more than** `⌊n / 2⌋` times.

The input is guaranteed to contain a majority element.

<!-- examples -->

**Constraints:**

- `n == nums.length`
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
- A majority element always exists.

**Follow-up:** Can you find it in linear time using only `O(1)` extra space?
