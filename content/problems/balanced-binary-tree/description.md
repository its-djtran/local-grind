Given the `root` of a binary tree, decide whether it is **height-balanced**.

A binary tree is height-balanced when, at **every** node, the heights of the left and right subtrees differ by at most one. (The height of a subtree is the number of nodes on its longest downward path; an empty subtree has height `0`.) An empty tree is balanced.

<!-- examples -->

**Constraints:**

- The tree contains between `0` and `5000` nodes.
- `-10^4 <= Node.val <= 10^4`
