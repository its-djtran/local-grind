Given an integer array `nums`, find every triplet of values `[nums[i], nums[j], nums[k]]` taken from three **different positions** (`i`, `j`, `k` pairwise distinct) whose sum is `0`.

The result must not contain the same triplet twice: two triplets count as the same if they consist of the same three values. You may return the triplets in any order, and the values inside each triplet in any order.

<!-- examples -->

**Constraints:**

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`
