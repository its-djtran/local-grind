In a binary tree, a **path** is a sequence of nodes where each consecutive pair is joined by an edge, and no node appears more than once. A path must contain at least one node, and it does not have to pass through the root.

The **path sum** is the total of the values of the nodes on the path.

Given the `root` of a binary tree, return the largest path sum over all non-empty paths in the tree.

<!-- examples -->

**Constraints:**

- The tree contains between `1` and `3 * 10^4` nodes.
- `-1000 <= Node.val <= 1000`
