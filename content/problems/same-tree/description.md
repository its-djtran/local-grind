You are given the roots `p` and `q` of two binary trees. Decide whether the two trees are **identical**.

Two trees count as identical when they have exactly the same shape and every pair of nodes in matching positions stores the same value. Return `true` if they are identical and `false` otherwise.

<!-- examples -->

**Constraints:**

- Each tree contains between `0` and `100` nodes.
- `-10^4 <= Node.val <= 10^4`
