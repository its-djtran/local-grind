Given an integer array `nums`, find a contiguous, non-empty subarray whose elements have the **largest product**, and return that product.

The tests are built so that the answer fits in a 32-bit integer.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- The product of any subarray of `nums` fits in a 32-bit integer.
