You are given a string `s` and a list of words `wordDict`. Decide whether `s` can be cut into a sequence of one or more pieces such that **every piece is a word from `wordDict`**. Return `true` if such a cut exists and `false` otherwise.

Any dictionary word may be used any number of times, and some words may not be used at all.

<!-- examples -->

**Constraints:**

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` and every `wordDict[i]` contain only lowercase English letters.
- The words in `wordDict` are all distinct.
