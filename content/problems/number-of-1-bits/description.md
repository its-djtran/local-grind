Given a positive integer `n`, count how many `1` digits appear in its binary representation and return that count. (This count is also known as the **Hamming weight** or population count of `n`.)

<!-- examples -->

**Constraints:**

- `1 <= n <= 2^31 - 1`

**Follow-up:** Suppose this function is called a very large number of times. How would you make each call as cheap as possible?
