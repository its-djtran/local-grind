Given a string `s`, find the longest contiguous substring of `s` that is a **palindrome**, meaning it reads the same forwards and backwards, and return it.

In general, several different substrings can tie for the maximum length. To keep answers unambiguous, **every test for this problem has exactly one longest palindromic substring**, so the answer is unique.

<!-- examples -->

**Constraints:**

- `1 <= s.length <= 1000`
- `s` contains only English letters and digits.
- The longest palindromic substring of `s` is unique.
