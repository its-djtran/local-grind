You are given an unsorted integer array `nums`. Find the longest run of **consecutive integers** `x, x + 1, x + 2, ..., x + m - 1` such that every value of the run appears somewhere in `nums`, and return its length `m`. The values may appear in any order and positions, and repeated values count only once.

An empty array has answer `0`.

Your algorithm must run in `O(n)` time.

<!-- examples -->

**Constraints:**

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
