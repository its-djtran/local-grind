Given two strings `s` and `t`, return `true` if `t` is an **anagram** of `s`, and `false` otherwise.

`t` is an anagram of `s` when it uses exactly the same letters as `s`, each the same number of times, possibly in a different order.

<!-- examples -->

**Constraints:**

- `1 <= s.length, t.length <= 5 * 10^4`
- `s` and `t` contain only lowercase English letters.

**Follow-up:** How would your solution change if the strings could contain arbitrary Unicode characters?
