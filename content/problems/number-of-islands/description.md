You are given an `m x n` map `grid` in which every cell is either `'1'` (land) or `'0'` (water). Return how many **islands** the map contains.

An island is a maximal group of land cells joined together **horizontally or vertically** (diagonal neighbors do not count). Everything outside the grid is water.

<!-- examples -->

**Constraints:**

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 300`
- `grid[i][j]` is `'0'` or `'1'`.
