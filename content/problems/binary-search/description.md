You are given an array of integers `nums` sorted in strictly increasing order, and an integer `target`. Return the index of `target` in `nums`, or `-1` if `target` does not appear in the array.

Your algorithm must run in `O(log n)` time.

<!-- examples -->

**Constraints:**

- `1 <= nums.length <= 10^4`
- `-10^4 < nums[i], target < 10^4`
- All values in `nums` are distinct.
- `nums` is sorted in ascending order.
